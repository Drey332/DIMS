Failed to execute 'fetch' on 'Window': '/api/team-members' is not a valid HTTP method.
means one (or more) of the following:

Your frontend is making a fetch call to /api/team-members, but your backend API is at /api/team (not /api/team-members).

The HTTP method being used might not be supported (for example, maybe your form is using GET instead of POST).

How to Fix (CEO/CTO Mindset):
1. Correct the API Endpoint
Change all your frontend fetch calls from /api/team-members to /api/team.

POST /api/team → Add member

GET /api/team → Get all members

PUT /api/team/:id → Edit member

DELETE /api/team/:id → Remove member

4. Restart Backend After Changes
If you modify backend code or endpoints, always restart your backend/server so changes take effect.

Forward-thinking & Developer-CEO Tips:
Always make your frontend API calls use the same routes as your backend. Consistency is key!

If you rename routes, update both frontend and backend.

Add a global error handler to your frontend so you see more details (helpful for debugging in the future).

Add logging on the backend (console.log(req.body)) to see what’s coming in if you hit issues.

async function addMember({ name, email, number, rank }, token) {
  const resp = await fetch('/api/team', {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer " + token
    },
    body: JSON.stringify({ name, email, number, rank })

  if (!resp.ok) throw new Error("Failed to add member");
