# DIMS (Dynamic Incident Management System)

HydroSafe/DIMS is an AI-powered safety and emergency management platform.
It helps predict risks (like gas leaks, equipment failures), guides response
through dynamic ERPs, and supports offshore, mining, and industrial operations.

## Features
- Predictive incident detection
- ERP authoring with AI
- Zone-based hazard mapping
- Drill mode simulation
- Real-time alerts and mustering

## Development
- client/: React app
- server/: APIs (AI ERP Advisor, Firestore integration)
- Firestore: project data storage
